# TYFINO Engineering Evidence

This directory is the canonical index/metadata location for attributable engineering evidence.

Use exact source SHAs, CI run IDs/URLs, checksums, device/runtime records, approved artifacts, and other task-specific proof as appropriate.

Do not commit secrets, credentials, signing material, activation codes, private keys, recovery codes, or secret-bearing URLs.

Large or externally retained artifacts may be referenced rather than duplicated here.
